# StoryTime (iOS)

Bedtime stories app for parents: free stories, a monthly subscription for the full library, and a
scanner that reads a code from our printed books to unlock the matching audio.

- SwiftUI, iOS 16+. Open `StoryTime.xcodeproj` (not in this export) or read the sources in `StoryTime/`.
- Submission notes for App Review: `docs/review-notes.md`.
